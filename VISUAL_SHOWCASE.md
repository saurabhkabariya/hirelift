## Responsive Design

All components are fully responsive:

### Desktop (1024px+)
- QuickAnswer: Full width, 2-column layout
- FAQ: Expandable cards, side-by-side
- Table of Contents: Sticky right sidebar
- How-To: 2 columns for steps

### Tablet (640-1023px)
- QuickAnswer: Full width, stacked
- FAQ: Full width stacked
- Table of Contents: Horizontal scrollable
- How-To: Single column, full width

### Mobile (< 640px)
- QuickAnswer: Simplified, centered
- FAQ: Stacked accordion
- Table of Contents: Hidden or collapsible
- How-To: Full width, numbered clearly

## Animation Examples

### QuickAnswer
- Fade in on mount: `opacity 0 → 1` (300ms)
- Slide up: `y: -10 → 0` (300ms)

### FAQs
- Button hover: Color transition (150ms)
- Answer expand: Smooth expand with framer (200ms)
- Item hover: Background color change (150ms)

### How-To Steps
- Stagger on mount: Each step appears in sequence
- Slide in from left: `x: -10 → 0` per step
- Delay: 50ms between each step

### Table of Contents
- Active indicator: Smooth color transition (200ms)
- Scroll spy: Real-time heading detection
